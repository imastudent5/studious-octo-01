弦月小提琴社招新网站 · 使用说明（朴素版）
========================================
（课程作业：第二次上机作业 work2.html，学号末位 2 → 小提琴社）

一、文件夹结构（整套上传到 GitHub 仓库根目录）
    li-0112-work2.html      ← 招新主页（提交链接用的就是它）
    club_intro.html         ← 活动介绍页（点击主页图片进入，页首页尾都可返回主页）
    images/                 ← 三张图片：performance.jpg / lesson.jpg / concert.jpg
    audio/theme.mp3         ← 背景音乐《梧桐下的少年》（1 分 30 秒，160 kbps，约 1.8 MB）
    video/club.mp4          ← 短片（mp4，39 秒，H.264，1.3 MB，用 <embed> 播放）
    ※ 保持这种相对位置上传，不要单独挪动 html 文件，否则图片和音视频会找不到。

二、页面风格说明
    按你的要求改成了“朴素版”：白底黑字、默认字体，没有深色主题、背景图、渐变、
    卡片、悬浮按钮等装饰；只保留了作业必需的表格、三张图片（要能点击跳转）和视频，
    正文全部是文字。CSS 只剩几十行，只做基本的行距、页面宽度和表格边线。

三、作业 7 项要求对应位置
    1. 背景音乐 —— 页面左上角的播放器（<audio src="audio/theme.mp3" controls loop>，
       参考 ex3_23），点播放键即响，可暂停、可循环。
    2. 五个跳转链接 —— 标题下方的“快速跳转”一行（社团简介 / 活动安排 / 风采展示 /
       社员故事 / 在线报名），用 <a name> 定位（参考 ex3_12）；每一节末尾都有
       “↑ 一键返回顶部”，共五个。
    3. 活动安排表 —— 第一行「弦月小提琴社 2026 年春季学期活动安排表」colspan=4；
       第二行表头居中；【新成员见面会】与【小提琴基础教学公开课】共用
       “音乐楼 A305 排练厅”那一格（rowspan=2，同一间教室）；另有 colspan=2 的行
       （参考 ex3_16）。
    4. 图片超链接 —— 三张图片都包在 <a href="club_intro.html"> 里（参考 ex3_19/3_20），
       介绍页首尾各有“← 返回弦月小提琴社招新主页”。
    5. 视频 —— <embed src="video/club.mp4" width="640" height="480" loop="true">（参考 ex3_25）。
    6. 社员故事 —— 约 1360 字，末尾有“↑ 一键返回顶部”。
    7. 在线报名表 —— 十项全部在 <table border="1"> 里：姓名 text、性别单选、
       出生日期三个 text、手机+邮箱 text、是否有基础单选、兴趣方向多选、
       年级下拉（大一～研究生）、自我介绍 textarea、是否服从单选、submit+reset
       （参考 ex3_30）。
    正文五节分别为 1498 / 1268 / 1275 / 1363 / 1261 字，均超过 1000 字。

四、素材替换（文件名不变就不用改代码）
    音乐：已经是海绵音乐生成并下载的《梧桐下的少年》(imastudent5)，160 kbps 转码版；
          若要换歌，同样改成 theme.mp3 覆盖 audio/theme.mp3 即可。
    视频：剪映导出的 mp4 → 改名 club.mp4，覆盖 video/club.mp4（导出时选 H.264，
          不要选 HEVC/H.265，否则 Chrome 可能播不出来）。
    图片：三张图片已经换成文心一言生成的实拍风格照片（宽 1400 像素、每张 120–270 KB）：
          performance.jpg（日常排练）、lesson.jpg（分组课）、concert.jpg（结课音乐会）。
          若要再换，覆盖同名文件即可，建议宽度不超过 1400 像素。
    现在的音乐和视频取自参考素材包（music.mp3 / movie.mp4），可再替换成自己生成的。

五、上传 GitHub
    1. 新建 public 仓库，把本文件夹里的 HTML 与三个子文件夹一起上传。
    2. Settings → Pages → Source 选 main 分支 / root，保存。
    3. 一分钟后访问 https://用户名.github.io/仓库名/li-0112-work2.html
       把这条链接填进 QQ 群共享 Excel。
    4. 单文件上限 25 MB，本套共约 5.2 MB。

六、小提示
    · 直接双击 li-0112-work2.html 就能预览；音乐需要点播放键（浏览器禁止自动播放）。
    · 报名表没有后台，点“提交报名”会弹出提示并显示确认信息，不会真正发送。
